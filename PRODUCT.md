# Пиксель Тулс onboarding/paywall prototype

## Product truth

Тестовый прототип проверяет гипотезу: пользователь с уже созданным GEO-проектом охотнее активирует пробный доступ за 99 ₽, если до оплаты может посмотреть готовый демо-отчёт.

## Scope

- Один статический frontend без backend, авторизации, API и базы данных.
- Четыре состояния: собственный проект, демо-сводка, демо-конкуренты, демо-рекомендации.
- Рабочие переходы: демо CTA, scroll pop-up, welcome overlay, 3 пункта sidebar, возврат к своему проекту.
